# 🚀 Initial Deployment Guide — Gautham Portfolio

This guide covers deploying the portfolio to **Vercel**, the recommended hosting platform.
The project is pre-configured with a [`vercel.json`](./vercel.json) and a Vite build pipeline — no extra configuration is needed.

---

## Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- [npm](https://www.npmjs.com/) v9 or higher
- A [GitHub](https://github.com/) account
- A [Vercel](https://vercel.com/) account (free tier is sufficient)

---

## Step 1 — Verify the Local Build

Before deploying, confirm the production build compiles cleanly:

```bash
npm install
npm run build
```

The optimized output will be generated in the `dist/` directory. You can preview it locally with:

```bash
npm run preview
```

> Open `http://localhost:4173` to verify everything looks correct before going live.

---

## Step 2 — Push to GitHub

If the project is not already on GitHub, initialize a repository and push:

```bash
git init
git add .
git commit -m "feat: initial portfolio commit"
git remote add origin https://github.com/YOUR_USERNAME/gautham-portfolio.git
git push -u origin main
```

> Replace `YOUR_USERNAME` with your actual GitHub username.

---

## Step 3A — Deploy via Vercel Dashboard *(Recommended)*

1. Go to [vercel.com](https://vercel.com) and sign in using your GitHub account.
2. Click **"Add New Project"**.
3. Select and import your `gautham-portfolio` repository.
4. Vercel will auto-detect **Vite** as the framework. Confirm the following settings:

   | Setting | Value |
   |---|---|
   | Framework Preset | `Vite` |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Install Command | `npm install` |

5. Click **"Deploy"**.

Your site will be live on a Vercel `.vercel.app` URL within ~30 seconds. ✅

---

## Step 3B — Deploy via Vercel CLI *(Alternative)*

1. Install the Vercel CLI globally:
   ```bash
   npm i -g vercel
   ```

2. Authenticate:
   ```bash
   vercel login
   ```

3. Run the deploy command from the project root:
   ```bash
   vercel
   ```
   Follow the interactive prompts. For a production deployment:
   ```bash
   vercel --prod
   ```

---

## Step 4 — Add a Custom Domain *(Optional)*

1. In the Vercel dashboard, go to your project → **Settings** → **Domains**.
2. Click **"Add Domain"** and enter your custom domain (e.g., `gautham.dev`).
3. Update your domain registrar's DNS with the records Vercel provides (usually a CNAME or A record).
4. Vercel will automatically provision an SSL certificate.

---

## Continuous Deployment

Once connected to GitHub, **every push to `main` triggers an automatic redeploy**. No manual action is needed after the initial setup.

Pull request previews are also created automatically for every branch — ideal for testing changes before going live.

---

## Project Configuration Reference

| File | Purpose |
|---|---|
| [`vercel.json`](./vercel.json) | SPA routing rewrites so all routes resolve to `index.html` |
| [`vite.config.js`](./vite.config.js) | Vite build configuration |
| [`package.json`](./package.json) | Build scripts (`dev`, `build`, `preview`) |
| `dist/` | Production output directory (generated by `npm run build`) |

---

## Troubleshooting

| Issue | Fix |
|---|---|
| Blank page after deploy | Confirm Output Directory is `dist` in Vercel settings |
| PDF not loading | Ensure `Gautham_CV.pdf` is inside the `public/` directory |
| Routes returning 404 | Verify `vercel.json` rewrites are present |
| Build errors | Run `npm run build` locally first to catch errors before pushing |
